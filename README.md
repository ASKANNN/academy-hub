# Askan Academy

Стартовая страница-хаб платформы Software Engineering Academy. Показывает
дерево академий по темам программирования: каждая академия — либо готовый
самостоятельный проект (ссылка наружу), либо запланированная ветка
с темами, которые появятся по мере готовности.

Открытый исходный код, лицензия MIT.

## Возможности

- Фиолетовый hero-баннер с анимацией нейросети (canvas, частицы + линии)
- Переключение светлой / тёмной темы (сохраняется в `localStorage`)
- Переключение языка RU / EN (Hero, Footer)
- Стеклянный хедер с backdrop-blur
- Адаптивная сетка карточек академий
- Hover-раскрытие списка тем внутри карточки

## Стек

Vite + React, без сторонних UI-библиотек. Дизайн-токены (`src/styles/tokens.css`)
используются как единственный источник цветов, типографики и отступов.

## Структура

```
src/
  components/
    Header.jsx      — логотип, переключатель RU|EN, кнопка темы
    Hero.jsx        — фиолетовый баннер с canvas-анимацией нейросети
    AcademyTree.jsx — адаптивная сетка карточек
    AcademyCard.jsx — карточка академии с hover-раскрытием тем
    Footer.jsx      — копирайт + ссылка на GitHub
    BrandMark.jsx   — SVG-логотип
    Icon.jsx        — иконки академий по id
  data/
    academies.js    — список академий: live (есть url) и planned (есть topics[])
  hooks/
    useTheme.js     — тема, хранится в localStorage
  styles/
    tokens.css      — дизайн-токены: цвета, типографика, отступы, тени
    base.css        — сброс стилей и базовая типографика
    app.css         — стили всех компонентов
```

## Как добавить академию

**Новая тема внутри академии** — дописать строку в `topics[]` нужной академии
в `src/data/academies.js`. Появится в карточке автоматически.

**Новая академия** — добавить объект в массив `ACADEMIES`:
```js
{
  id: 'my-academy',
  name: 'My Academy',
  tagline: 'Краткое описание',
  icon: 'icon-id',
  status: 'planned',   // или 'live'
  url: 'https://...',  // только для live
  topics: ['Тема 1', 'Тема 2'],
}
```
И добавить SVG-путь иконки в `GLYPHS` в `src/components/Icon.jsx`.

**Академия готова** — сменить `status: 'planned'` → `'live'`, указать `url`.
